# Rabbit

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Stack

Expo with React Native and gluestack UI, mobile first, with a web build for preview. Use current stable compatible versions where possible, as requested by the user.

## Users

Friends and small communities recording useful information and sharing it with selected people and private groups. The user confirmed this audience on 2026-10-30.

## Product Purpose

A private Reddit-like space built around posting useful information and retrieving it through search.

## Capabilities and Constraints

Users can post to themselves, another user, or a group. Members can add existing users to groups they belong to. Users can create groups and invite existing users. Home is an easy post composer with a search toggle. Recent and Profile are the other two primary tabs. Recent provides shortcuts into groups. Search covers accessible information only.

## Operating Context

Expo native app with a responsive web version. Initial local development and preview run in this repository. No external identity provider or hosted deployment was supplied.

## Evidence on Hand

The repository name is rabbit and has an existing geometric icon in assets/icon.svg. Example people, groups and posts are explicitly demonstration data.

## Product Principles

- Put writing and finding useful information first.
- Make the audience visible before posting.
- Keep group membership and access consistent across search and feeds.
- Make the core tasks comfortable on a phone.
