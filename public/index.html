Use Rabbit Goals with WebFetch

Ask the user for a goal ID and a Rabbit WebFetch token. They can sign in and open Goals, select the goal, then choose Goal options → Share with WebFetch → Create WebFetch token → Copy WebFetch access. The token starts with rg_, works for one goal, and expires after 15 minutes. Handle it privately and leave it out of replies and shared files.

Read a goal

WebFetch /api/agent/goals?goalId=GOAL_ID&token=WEBFETCH_TOKEN on this same origin. The JSON includes the goal and up to 10 tasks. If nextOffset is a number, add &offset=NEXT_OFFSET to fetch more.

Suggest a new task

WebFetch /api/agent/goal-suggestions?goalId=GOAL_ID&token=WEBFETCH_TOKEN&description=TASK_TEXT on this same origin. URL-encode each value. Use one task description of up to 500 characters per call. Resolve the returned reviewPath against this origin and give the full review link to the user. They sign in, review the task and choose Add task to goal to save it.
