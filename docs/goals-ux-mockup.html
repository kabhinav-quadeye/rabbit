1 · Goals home (390px). Momentum sentence leads, quoting the issue. Each goal shows its top 3 actionable leaf tasks. Ticking strikes the row in place with Undo, and Refresh gets a count badge. Nothing reorders until the person taps Refresh. Bottom nav grows to four tabs (min 80px each, which fits 390px).

2 · Goal page. The tree is shown in creation order, with completed tasks hidden by default ("Show done · 8"). "Up next" uses the same ranked leaf list as Home. The add bar is docked at the bottom and rises with the keyboard. It stays focused after each submit so the person can break a goal down quickly.
